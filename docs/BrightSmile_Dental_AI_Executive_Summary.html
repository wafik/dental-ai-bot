Deterministic Scope Enforcement

Medical authorizations are enforced deterministically in the application core (AppointmentService), never left to the discretion of an LLM prompt. If a patient attempts to schedule oral surgery with Dr. Junior, the scheduling engine rejects the assignment and seamlessly reroutes to an available senior doctor.

Operational Safety & Zero-Trust Governance Patient Protection Standards
Adversarial Prompt Shield

Pre-parsing filters reject prompt injection patterns (such as instructions to ignore clinical rules or extract internal instructions) before triggering downstream LLM context, ensuring predictable behavior and avoiding wasted compute.

Clinical Advice Deflection

The conversational assistant strictly avoids providing diagnoses or medication prescriptions. Any inquiry regarding acute distress triggers clear guidance directing the patient to seek urgent clinical evaluation.

Privacy & Credential Hygiene

Primary API secrets and OAuth credentials stay strictly on the server. Audio is processed transiently in memory, preventing persistent capture of voice recordings while maintaining patient confidentiality.

Three-Phase Lifecycle Execution
  • 1. Ephemeral Handshake: The browser requests a temporary session secret via POST /api/v1/voice/session. The backend generates a short-lived token (<60 seconds), keeping long-term keys secure on the server.
  • 2. Direct Media Stream: WebRTC establishes a peer-to-peer connection for bidirectional Opus audio, eliminating transcription bottlenecks.
  • 3. Server-Verified Tool Calling: When an appointment is scheduled, function calls transmit across the WebRTC DataChannel to /api/v1/voice/tools for authoritative database validation.

Google Calendar Adapter

Executes batch FreeBusy interval queries for target practitioner calendars. Manages proactive OAuth 2.0 token refreshes in memory 5 minutes prior to expiry.

Microsoft 365 Outlook Adapter

Connects to Microsoft Graph calendarView via Entra ID app credentials. Recursively drains paginated busy blocks and normalizes timestamps to UTC RFC3339 format.

Dynamic Database Settings

Practitioner calendar addresses are stored in a dedicated database table, enabling clinic administrators to adjust calendar mappings through the web UI without redeploying code.

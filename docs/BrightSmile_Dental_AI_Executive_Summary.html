Deterministic Scope Enforcement

Qualification is enforced in AppointmentService, never by the model's prompt. If a patient asks for a root canal with Dr. Junior, the server raises DentistQualificationError and the assistant reroutes to an eligible specialist.

Voice & Calendar Mechanics Streaming & eventual convergence
Realtime Voice

PCM16 audio streams over a WebSocket at 16 kHz up and 24 kHz down, with no separate speech-to-text hop. Tool calls are relayed to /api/v1/voice/tools for server-side validation. Master provider keys never reach the browser.

Dual Calendar

Google Calendar (API v3 FreeBusy) and Microsoft Graph (calendarView) sit behind one provider contract. A booking stays pending until both providers converge; per-provider retry state is drained by an authenticated reconcile endpoint.

Credential Handling

OAuth secrets live in an AES-256-GCM encrypted store managed from /admin, or in environment variables as a bootstrap fallback. The admin API returns configured status only, never the stored value.

Why voice deserves the scrutiny

Voice is the one line item large enough to distort a small clinic's software budget. Hosted realtime audio is priced per minute, so a practice handling a few thousand spoken minutes a month pays more for voice than for everything else combined.

That is a property of per-minute voice pricing, not of this application. The same code pointed at a self-hosted OpenAI Realtime-compatible server — for example huggingface/speech-to-speech — costs only electricity. Choose the provider you can actually fund; the application does not choose for you.

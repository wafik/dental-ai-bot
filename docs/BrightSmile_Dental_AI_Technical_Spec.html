Low-Latency Protocol Exchange

1. Provider Selection: GET /api/v1/voice/session reports the configured provider so the browser can choose a transport without spending a single-use token.
2. Session Descriptor: POST /api/v1/voice/session returns the endpoint, model and credentials. With Gemini Live the backend mints a single-use token; master credentials never leak to the client.
3. Media Stream: Audio streams as base64 PCM16 over WebSocket — 16 kHz up, 24 kHz down — with no separate STT hop.
4. Tool Dispatch: The model emits a function call; the browser relays it to POST /api/v1/voice/tools for backend validation, then returns the result to the model.

30-Minute Quantization Algorithm

Operating hours (09:00 - 17:00) partition into discrete 30-min steps. Candidate intervals must fully accommodate service duration (slot.end <= 17:00) without intersecting existing appointments: !(candidate.end <= busy.start || candidate.start >= busy.end).

3. Edge Guardrails & Security Perimeter Pre-Execution Sanitization
Prompt Injection Defenses

Regex edge filter screens incoming text against known jailbreak primitives (ignore previous instructions, DAN, system extraction). Injections are halted prior to token dispatch, incurring 0ms LLM compute and $0.00 spend.

Medical Triage Boundary

Clinical queries requesting medical diagnoses, toothache infection prognoses, or antibiotic prescriptions are intercepted immediately. The system outputs a standard medical disclaimer advising in-person emergency evaluation.

HIPAA Zero-Retention Ingestion

Voice payloads stream in volatile memory buffers. Audio frames are dropped from memory upon session closure. Master OAuth keys and Entra ID secrets reside strictly in environment variables or encrypted parameter stores.

Collision Avoidance & Isolation

To prevent concurrent booking race conditions when multiple voice lines settle simultaneously:
1. Availability Query: Reads pending and confirmed bookings for the targeted doctor and date.
2. Provider Intersect: Combines DB slots with live Google/MS Graph busy intervals.
3. Atomic Reservation: Inside a PostgreSQL transaction, acquires a transaction-scoped advisory lock keyed by dentist and date, re-checks interval overlap, and inserts a pending reservation. Competing transactions abort with SlotUnavailableError; the assistant offers the next available slot.

Settings Stores: clinic_settings & dentist_calendar_mappings enable live provider reconfiguration without container redeploys.
5. Dual-Calendar Adapter Contract & Normalization Provider-Neutral Calendar Abstraction
Google Calendar Adapter

Queries v3/freeBusy batch endpoint. Converts local date ranges to RFC3339 UTC strings with trailing Z. Implements proactive in-memory OAuth 2.0 refresh rotation 5 minutes prior to token expiry.

Microsoft 365 Outlook Adapter

Executes Microsoft Graph calendarView via Entra ID client-credentials flow. Recursively drains multi-page @odata.nextLink results. Canonicalizes dateTimeTimeZone payloads to UTC ISO-8601.

Dynamic Provider Factory

The CalendarFactory queries clinic_settings at runtime to resolve the active provider (google | outlook). Calendar addresses are queried from dentist_calendar_mappings with graceful env fallbacks.
